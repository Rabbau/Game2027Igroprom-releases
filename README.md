# Торговец и некромант

Тёмное фэнтези в двух сменах. **Днём** ты травник с лавкой на колёсах: варишь зелья вслепую, продаёшь их деревне и слушаешь, что о тебе говорят. **Ночью** ты некромант: поднимаешь мёртвых, допрашиваешь их и пробиваешься к цели через комнаты с боями в духе Hades.

## Как запустить

1. Распакуйте архив в любую папку.
2. Запустите `TorgovetsINekromant.exe`. Устанавливать ничего не нужно.
3. Windows может предупредить о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».

Нужна Windows 10 или 11 (64 бит) и видеокарта с OpenGL 3.3.

## Управление

| Где | Что |
|---|---|
| Везде | Esc — настройки, J — дневник, F8 — сообщить о проблеме, F11 — полный экран |
| День | Траву — в котёл, склянку — на прилавок (мышью). Щелчок по ставне — отказать. Пробел — пауза дня |
| Закат | Выбери на карте могилу или логово; слуг можно перетащить на отметки |
| Ночь | WASD — ход, ЛКМ — посох, ПКМ — Костяной шип, Пробел — рывок, Q — зелье, R — Вихрь душ, V — Костяной частокол, F — Слово упокоения, E — действие |

## Нашли ошибку?

Нажмите **F8** прямо в игре: снимок экрана и ваша заметка сохранятся в лог. Папку с логами открывает кнопка «Папка логов плейтеста» на титульном экране — пришлите её содержимое разработчику.
